  Reduced Motion, keyboard support and external-resource IPC/preview boundaries.

Known limits: alpha maturity; Windows 11 x64 is the primary locally verified target.
Linux/macOS remain experimental. Local Python is trusted user-level execution, not
a security sandbox. Experimental Windows Sandbox export is implemented, but its
optional OS component/GPU execution is unavailable on the local test host. LaTeX
is optional and not bundled; MOV playback depends on codecs. Packages are unsigned.
