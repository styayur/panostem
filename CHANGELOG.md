# Changelog

## 0.5.0-alpha.1

Panostem replaces the public STEM Visual Explorer name. The Tauri application
identifier and existing storage keys remain compatible; historical releases are
preserved. Actual publication evidence is in the release and delivery audit.

- Independent native ManimGL Studio with ordinary Python projects, five templates,
  multi-file editing, assets, project ZIPs and recoverable file trash.
- Application-managed Python 3.11.14 and immutable 3b1b/manim v1.7.2 source;
  hash-locked packages, environment diagnostics and separately authorized project
  dependencies. Upstream's 1.7.1 banner discrepancy and FPS workaround are documented.
- Real native OpenGL/IPython preview, console line input, bounded task logs/history,
  one-hour timeouts, process-tree cancellation and failed-output cleanup.
- Video/final-frame rendering, generated thumbnails, playback and output locations.
- Versioned optional ontology-linked metadata and explicit typed parameter contract.
- Versioned, path/size/hash-validated local share ZIPs with opt-in Python source;
  static Web playback with no Python execution and a real rendered example.
- Preserved numerical JSXGraph lessons, concept search, learning paths, three locales,
  Reduced Motion, keyboard support and external-resource IPC/preview boundaries.
- Actual dependency inventories/license texts, updated guides/screenshots, rendering
  CI and prerelease-aware Windows packaging with SHA-256 checksums.

Known limits: alpha maturity; Windows 11 x64 is the primary locally verified target.
Linux/macOS remain experimental. Local Python is trusted user-level execution, not
a security sandbox. Experimental Windows Sandbox export is implemented, but its
optional OS component/GPU execution is unavailable on the local test host. LaTeX
is optional and not bundled; MOV playback depends on codecs. Packages are unsigned.
